## NeoShy Remote Tool

Modern all-in-one Android toolkit for Windows — ADB, Fastboot, Xiaomi flash, Samsung (Heimdall), Payload dump, and Scrcpy mirroring in one dark-themed desktop app.

---

### What's included

**ADB**
- Start / Kill ADB server
- Reboot: System · Recovery · Fastboot
- Sideload ZIP · Install APK
- Clipboard sync (PC ↔ Phone)
- About Phone · Developer Options
- Built-in Terminal & File Explorer

**Fastboot**
- Flash Boot / Recovery / Init Boot
- Temporary boot image
- Slot A/B switch & flash targets
- Disable DM-Verity & VBMeta
- Format data (`fastboot -w`)
- Getvar All · Product · Check UBL

**Xiaomi**
- Select extracted firmware folder
- List & run `flash_all*.bat` scripts
- Progress indicator + safety confirmations

**Samsung (Heimdall)**
- Odin-style slots: BL · AP · CP · CSC · HOME · PIT
- Detect · Print PIT · Reboot
- Flash tar packages · Patch vbmeta

**Payload Dump**
- Built-in `payload.bin` / OTA ZIP dumper
- Selective partition extract
- Extract `.img` from firmware ZIPs

**Scrcpy Mirroring**
- Bitrate & FPS controls
- Quality presets (No Audio, Low Res, Safe Mode, etc.)
- Floating control panel while mirroring

---

### Requirements
- Windows 10 / 11 (64-bit)
- USB debugging enabled on the device
- Bundled binaries included (adb, fastboot, scrcpy, heimdall)

---

### ⚠️ Warning
Flashing firmware or partitions **can brick your device**.  
Always verify model, region, slot, and image files before flashing.  
Use at your own risk.
